# Fantasy Travel optional resources

This resource pack is optional. The data pack must remain playable without it.

Use the `fantasy_travel` namespace for client assets:

- `assets/fantasy_travel/textures/`
- `assets/fantasy_travel/items/`
- `assets/fantasy_travel/models/`
- `assets/fantasy_travel/lang/`
- `assets/fantasy_travel/sounds/`
- `assets/fantasy_travel/font/`

Every data-pack feature that references a custom asset must provide a vanilla fallback.
